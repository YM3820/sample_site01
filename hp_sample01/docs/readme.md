# ボタンアニメーション サンプルサイト

このサイトは、ボタンを「見つけやすく、押したことが分かりやすく、楽しく操作できる」ようにするアニメーションのサンプルです。

[北浦和阿波おどり公式サイト](https://kitaurawa.or.jp/)の軽快なボタン表現を参考にしながら、一般的なWebサイトへ組み込みやすい独立した仕組みとして作成しています。参考サイト固有の画像、ロゴ、文章は使用していません。

## このサイトで確認できること

ページを開き、上から順番に操作すると、次の動きを確認できます。

1. 最初のボタンが時間差で弾むように登場します。
2. マウスをボタンへ重ねると、少し浮き上がって光が横切ります。
3. ボタンを押している間は、少し沈んで押下感が出ます。
4. Primaryボタンは、周囲が控えめに発光します。
5. 「送信する」では、処理中表示と二重操作防止を確認できます。
6. 「お祝いする」では、画面全体に花火が上がります。
7. 「もう一度」では、押した位置から小さな火の粉が広がります。

## サイト構成

サンプルは1ページで構成されています。

| エリア | 内容 |
|---|---|
| ヒーロー | サイトの概要と3種類のリンク型ボタン |
| ボタン種別 | Primary、Secondary、Quietの見た目を比較 |
| 状態 | 通常、処理中、無効状態を比較 |
| クリック演出 | 花火と火の粉のオプション演出 |
| フッター | モーション低減設定についての案内 |

画面幅が480px以下の場合、ボタンは押しやすいよう横幅いっぱいに表示されます。ページ本体の最大幅は960pxです。

## ボタンの種類

### Primary

ページ内で最も重要な操作に使う赤いボタンです。

- 背景色付きで、最も目立つデザイン
- 登場後に周囲がゆっくり発光
- 発光が不要な場合は `data-motion-pulse="off"` で停止可能
- 1画面に多用せず、重要な操作へ絞って使う想定

### Secondary

Primaryを補助する赤い枠線のボタンです。

- 透明な背景と赤い枠線
- Primaryより目立ちすぎない
- 戻る、別の選択肢、補助操作などに使用

### Quiet

優先度の低い操作に使うシンプルなボタンです。

- 背景と影を抑えた表示
- ホバー時だけ薄い背景と影を表示
- 詳細表示など、主操作を邪魔したくない場合に使用

## アニメーション仕様

### 1. 登場アニメーション

`data-motion-group` が付いた領域が画面内へ20%ほど入ると、その直下のボタンが1回だけ順番に登場します。

- 1個の動作時間: 600ms
- 次のボタンが動き始めるまで: 120ms
- 開始時: 小さく、10px下にあり、透明
- 途中: 本来の大きさを少し越えて弾む
- 完了時: 通常の大きさと位置に戻る
- 一度表示されたグループは、スクロールして戻っても再実行しない

表示領域の監視には `IntersectionObserver` を使用しています。対応していない環境では、監視せず直ちに表示します。

### 2. ホバー

マウスなど、正確な位置を指定できる機器だけで実行します。

- 上へ4px移動
- 1.045倍に拡大
- 影を強くして浮遊感を表現
- 半透明の光沢が左から右へ600msで通過
- ホバー中はPrimaryの周期的な発光を止め、ホバーの影を優先

タッチ端末ではホバー演出を実行しないため、タップ後に浮いた状態が残りません。

### 3. 押下

ボタンを押している間、上方向の移動を1pxに戻し、0.98倍へ縮小します。明るさと影も少し抑え、実際に沈んだような感触を表現します。

変化時間は120msです。リンク遷移や処理の開始を、アニメーションの完了待ちで遅らせることはありません。

### 4. Primaryの発光

Primaryボタンでは、外側へ広がる赤い光を2.2秒周期で繰り返します。

登場アニメーションと発光が同時に動くとCSSの指定が競合するため、登場完了を確認してから発光を開始します。`data-motion-pulse="off"` を指定したボタンでは発光しません。

### 5. 処理中表示

「送信する」を押すと、サンプルとして1.8秒間の非同期処理を開始します。

- ボタン左側に回転するスピナーを表示
- `aria-busy="true"` で処理中であることを通知
- 一時的に `disabled` を設定して二重送信を防止
- 処理完了後に元の状態へ復元
- 結果は `aria-live="polite"` のメッセージ領域へ表示

実際の通信は行わず、待ち時間だけを再現しています。

### 6. 火の粉（burst）

`data-motion-effect="burst"` を指定したボタンで使用する軽量な演出です。

- マウス操作ではクリックした位置から発生
- キーボード操作ではボタン中央から発生
- PCは16個、幅700px未満は10個の粒を生成
- 粒の移動距離は24〜72px
- 動作時間は450〜750ms
- 赤、金、橙の3色
- 同じボタンの300ms以内の連打は抑制
- DOM上の粒は最大40個
- 終了した粒は自動的に削除

### 7. 打ち上げ花火（fireworks）

`data-motion-effect="fireworks"` を指定したボタンで使用する、画面全体の演出です。

- 押した瞬間にボタンの位置で小さく破裂
- その位置からPCは8発、幅700px未満は5発を順番に打ち上げ
- 牡丹、輪、柳、二重輪の4種類をランダムに表示
- 赤、金、橙、水色、緑、桃、紫、白を使用
- 火花は同時に最大1200個
- 同じボタンの500ms以内の連打は抑制
- Canvasを1枚だけ生成し、`requestAnimationFrame` で描画
- 描画する花火がなくなるとCanvasを自動的に削除

花火のCanvasはクリックを妨げず、読み上げ対象にもなりません。

## ボタンの状態

| 状態 | 表示と動作 |
|---|---|
| 通常 | 種別に応じた色、枠線、影を表示 |
| ホバー | 浮上、拡大、影、光沢を表示 |
| 押下中 | 少し縮小して暗くなる |
| キーボードフォーカス | 紺色の2pxアウトラインを表示 |
| 無効 | 半透明になり、影とアニメーションを停止 |
| 処理中 | スピナーを表示し、二重操作を防止 |

リンク型ボタンを無効にするときは `aria-disabled="true"` を使用します。見た目を変えるだけでなく、JavaScriptでリンク遷移も停止します。

## アクセシビリティ

操作方法や利用者の設定にかかわらず、基本機能を利用できるよう配慮しています。

- 画面遷移には `a`、画面内操作には `button` を使用
- すべてのボタンで44px以上の操作領域を確保
- Tabキーで移動したときにフォーカス位置を明示
- EnterキーとSpaceキーによる操作に対応
- 装飾用の火の粉とCanvasを読み上げ対象から除外
- JavaScriptが無効でもボタンを非表示にせず、リンクの基本機能を維持
- Windowsの強制カラーモードでは、枠線とフォーカス表示を優先

OSやブラウザーの「視差効果を減らす」「アニメーションを減らす」設定が有効な場合は、次の動きを停止します。

- ボタンの移動と拡大
- 登場アニメーション
- Primaryの発光
- 火の粉
- 打ち上げ花火
- 処理中スピナーの回転

動きを停止しても、色、枠線、文字、フォーカスリングによって状態を判別できます。設定がページ表示中に変更された場合も、進行中の火の粉と花火を消去します。

## 動かし方

静的なHTMLサイトなので、ビルドやパッケージのインストールは不要です。`index.html` をブラウザーで開くか、プロジェクトのルートでローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

起動後、ブラウザーで `http://localhost:8000/` を開きます。

## 別のサイトで使う方法

### 1. CSSとJavaScriptを読み込む

登場前の表示制御を正しく行うため、JavaScriptは `head` 内で同期読み込みします。

```html
<link rel="stylesheet" href="assets/styles/button-motion.css">
<script src="assets/scripts/button-motion.js"></script>
```

### 2. ボタンへクラスを付ける

```html
<a class="motion-btn motion-btn--primary" href="/detail/">
  詳細を見る
</a>

<button class="motion-btn motion-btn--secondary" type="button">
  閉じる
</button>
```

### 3. 順番に登場させる

```html
<div data-motion-group>
  <button class="motion-btn motion-btn--primary" type="button">決定</button>
  <button class="motion-btn motion-btn--secondary" type="button">戻る</button>
</div>
```

`data-motion-group` の直下にある `.motion-btn` が対象です。

### 4. クリック演出を選ぶ

```html
<button
  class="motion-btn motion-btn--secondary"
  type="button"
  data-motion-effect="burst"
>
  火の粉を表示
</button>

<button
  class="motion-btn motion-btn--primary"
  type="button"
  data-motion-effect="fireworks"
>
  花火を表示
</button>
```

演出属性を付けない通常ボタンでは、火の粉や花火は表示されません。

## JavaScript API

`button-motion.js` は、グローバルに `ButtonMotion` を公開します。

```js
ButtonMotion.init(root);
ButtonMotion.setLoading(button, true);
ButtonMotion.setLoading(button, false);
ButtonMotion.destroy(root);
```

| API | 用途 |
|---|---|
| `init(root)` | 後から追加したボタンや領域を初期化 |
| `setLoading(element, true)` | 処理中表示と操作不可状態を開始 |
| `setLoading(element, false)` | 処理前の状態へ復元 |
| `destroy(root)` | イベント、表示監視、生成中の演出を破棄 |

ページ読み込み時は自動的に `document` 全体を初期化するため、静的なHTMLだけなら `init()` を手動で呼ぶ必要はありません。

## 色や速度の変更

主な設定はCSSカスタムプロパティへまとめています。

```css
:root {
  --motion-accent: #c1272d;
  --motion-accent-rgb: 193, 39, 45;
  --motion-focus: #1f3a5c;
  --motion-enter: 600ms;
  --motion-stagger: 120ms;
  --motion-pulse: 2.2s;
  --motion-radius: 999px;
}
```

サイトのブランドカラーに合わせる場合は、`--motion-accent` と `--motion-accent-rgb` の両方を同じ色へ変更してください。

## 実装上の考え方

- 通常のホバー、押下、フォーカスはCSSで処理します。
- JavaScriptは表示タイミング、処理中状態、火の粉、花火だけを担当します。
- 位置や大きさのアニメーションには主に `transform` を使います。
- 本来のクリック処理やリンク遷移は、演出の完了を待ちません。
- 火の粉やCanvasは演出終了後に削除し、ページ内へ残しません。
- 初期化は同じ要素へ複数回呼んでも、イベントを重複登録しません。

より細かな数値、テスト条件、受け入れ条件は [設計書20260929.md](./設計書20260929.md) を参照してください。
